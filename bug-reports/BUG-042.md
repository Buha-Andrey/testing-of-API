## BUG-042: 405 Method Not Allowed is returned on PUT/PATCH/DELETE endpoints when booking ID is set to non-numeric value 
**Priority:** P3  
**Severity:** Minor    
**Created by:** Buha Andrii    

**Endpoint:** `PUT /booking/{id}`, `PATCH /booking/{id}`, `DELETE /booking/{id}`    
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
PUT/PATCH/DELETE endpoints return 405 Method Not Allowed instead of 400 Bad Request when booking ID is a non-numeric value. Note that request is still failed. This issue reproduces for `PUT /booking/{id}`, `PATCH /booking/{id}` and `DELETE /booking/{id}` endpoints.

### Steps to reproduce
1. Send a `PUT /booking/abc`
2. Check status code

### Expected result
400 Bad Request     
### Actual result 
405 Method Not Allowed
