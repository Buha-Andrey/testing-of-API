## BUG-018: Sending request with non-positive numeric value  of `totalprice` property returns 200 OK instead of 422 Unprocessable Entity
**Priority:** P1  
**Severity:** Critical    
**Created by:** Buha Andrii    

**Endpoint:** `POST /booking`   
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
Request with with non-positive numeric value  of `totalprice` field returns status code 200 OK instead of 422 Unprocessable Entity. The booking is created and totalprice is set without any error. This issue reproduces with zero value and negative numbers. 


### Steps to reproduce
1. Send a `POST /booking`
```
{
  "firstname": "Brandon",
  "lastname": "Sanderson",
  "totalprice": -1,  
  "depositpaid": true, 
  "bookingdates": {
    "checkin": "2025-01-01",  
    "checkout": "2026-01-01"  
  },
  "additionalneeds": "books"
}
```
2. Check status code

### Expected result
422 Unprocessable Entity     
### Actual result 
200 OK,  Response body "totalprice": -1
