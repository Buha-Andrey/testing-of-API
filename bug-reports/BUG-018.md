## BUG-018: 200 OK is returned on multiple endpoints when `totalprice` property is set to non-positive number
**Priority:** P1  
**Severity:** Critical    
**Created by:** Buha Andrii    

**Endpoint:** `POST /booking`, `PUT /booking/{id}`, `PATCH /booking/{id}`         
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
Request with with non-positive numeric value  of `totalprice` field returns status code 200 OK instead of 422 Unprocessable Entity. The booking is created and totalprice is set without any error. This issue reproduces with zero value and negative numbers. 
This issue reproduces across multiple endpoints: `POST /booking`,`PUT /booking/{id}`, `PATCH /booking/{id}` . Actual and expected results are the same for every endpoint.  


### Steps to reproduce
1. Send a `POST /booking`
```
{
  "firstname": "Brandon",
  "lastname": "Sanderson",
  "totalprice": -1,  
  "depositpaid": true, 
  "bookingdates": {
    "checkin": "2025-01-01",  
    "checkout": "2026-01-01"  
  },
  "additionalneeds": "books"
}
```
2. Check status code

### Expected result
422 Unprocessable Entity     
### Actual result 
200 OK,  Response body contains "totalprice": -1
