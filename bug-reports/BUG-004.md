## BUG-004: DELETE /booking/{id} endpoint returns status code 201 Created instead of 204 No Content for successful deleting of the booking  
**Priority:** P3  
**Severity:** Minor   
**Created by:** Buha Andrii   

**Endpoint:** `DELETE /booking/{id}`   
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
Status code 201 Created is returned when a booking is deleted via a `DELETE /booking/{id}` request. Actually we are waiting for status code 204 No Content. 

### Steps to reproduce
1. Send a `POST /auth` request with valid credentials to create an authorization token.
2. Send a `POST /booking` request to create a test booking. 
3. Send a `DELETE /booking/{id}` request to delete the test booking, using the authorization token obtained in step 1.
4. Check the status code in the response

### Expected result
204 No Content

### Actual result 
201 Created
