## BUG-001: /auth endpoint returns status code 200 OK instead of 401 Unauthorized for invalid credentials
**Priority:** P3  
**Severity:** Minor   
**Created by:** Buha Andrii   

**Endpoint:** POST /auth  
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
Status code 200 Ok is returned when sending POST /auth request with invalid credentials, instead of 401 Unauthorized. There are a few similar cases when this issue reproduces: incorrect password, incorrect username,  username's value is an empty string, password's value is an empty string

### Steps to reproduce
1. Send request POST /auth with the following data:
```
Header:
Content-Type: application/json

Request body:
{
"username": "admin",
"password": "wrongpassword"
}
```
 
2. Check the status code in the response


### Expected result
401 Unauthorized

### Actual result 
200 OK

### Additional info
Problem occurs only with the status code in the response. User don't authenticate with invalid credentials.
