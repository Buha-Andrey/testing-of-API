## BUG-021: Sending request with null value of `depositpaid` returns 500 Internal Server Error instead of 400 Bad Request
**Priority:** P2  
**Severity:** Major    
**Created by:** Buha Andrii    

**Endpoint:** `POST /booking`   
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
Request with null value of `depositpaid` field returns status code 500 Internal Server Error instead of 400 Bad Request

### Steps to reproduce
1. Send a `POST /booking`
```
{
  "firstname": "Brandon",
  "lastname": "Sanderson",
  "totalprice": 1000
  "depositpaid": null, 
  "bookingdates": {
    "checkin": "2025-01-01",  
    "checkout": "2026-01-01"  
  },
  "additionalneeds": "books"
}
```
2. Check status code

### Expected result
400 Bad Request     
### Actual result 
500 Internal Server Error
