## BUG-026: 200 OK is returned on multiple endpoints when `checkin`/`checkout` properties are set to a year-only format
**Priority:** P1  
**Severity:** Critical    
**Created by:** Buha Andrii    

**Endpoints:** `POST /booking`, `PUT /booking/{id}`   
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
Request with just year (e.g. "2018") of `checkin`/`checkout` fields returns status code 200 OK instead of 422 Unprocessable Entity. The booking is created and `checkin`/`checkout` is set to a 1st day and 1st month of entered year without any error.
This issue reproduces across multiple endpoints: `POST /booking`, `PUT /booking/{id}`. Actual and expected results are the same for every endpoint.  


### Steps to reproduce
1. Send a `POST /booking`
```
{
  "firstname": "Brandon",
  "lastname": "Sanderson",
  "totalprice": 1000
  "depositpaid": true, 
  "bookingdates": {
    "checkin": "2018",  
    "checkout": "2026-01-01"  
  },
  "additionalneeds": "books"
}
```
2. Check status code

### Expected result
400 Bad Request     
### Actual result 
200 OK , Response body: "checkin": "2018-01-01"
