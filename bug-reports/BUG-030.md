## BUG-030: 405 Method Not Allowed is returned on PUT/PATCH endpoints when booking ID does not exist
**Priority:** P3  
**Severity:** Minor    
**Created by:** Buha Andrii    

**Endpoint:** `PUT /booking/{id}`   
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
PUT/PATCH endpoints return 405 Method Not Allowed instead of 404 Not Found when booking ID does not exist. Note that request is still failed. This issue reproduce for PUT /booking/{id} and PATCH /booking/{id} endpoint.

### Steps to reproduce
1. Send a `PUT /booking/999999`
2. Check status code

### Expected result
404 Not Found     
### Actual result 
405 Method Not Allowed
