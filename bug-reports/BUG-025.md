## BUG-025: Sending request with invalid date format of `checkin`/`checkout`fields returns 200 OK instead of 400 Bad Request
**Priority:** P1  
**Severity:** Critical    
**Created by:** Buha Andrii    

**Endpoint:** `POST /booking`   
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
Request with invalid date (e.g. "2018-13-32") format of `checkin`/`checkout` fields returns status code 200 Internal Server Error instead of 400 Bad Request. The booking is created and `checkin`/`checkout` is set to a `"0NaN-aN-aN"` value without any error.

### Steps to reproduce
1. Send a `POST /booking`
```
{
  "firstname": "Brandon",
  "lastname": "Sanderson",
  "totalprice": 1000
  "depositpaid": true, 
  "bookingdates": {
    "checkin": "2018-13-32",  
    "checkout": "2026-01-01"  
  },
  "additionalneeds": "books"
}
```
2. Check status code

### Expected result
400 Bad Request     
### Actual result 
200 OK , Response body: "checkin": "0NaN-aN-aN"
