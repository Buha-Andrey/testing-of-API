## BUG-040: PATCH /booking/{id} returns 200 OK when `checkin`/`checkout` properties are set to null
**Priority:** P1  
**Severity:** Critical    
**Created by:** Buha Andrii    

**Endpoint:** `PATCH /booking/{id}`   
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
Request with null of `checkin`/`checkout` fields returns status code 200 OK instead of 400 Bad Request. The booking is created and `checkin`/`checkout` is set to "1970-01-01" without any error.

### Steps to reproduce
1. Send a `POST /booking`
```
{
  "firstname": "Brandon",
  "lastname": "Sanderson",
  "totalprice": 1000
  "depositpaid": true, 
  "bookingdates": {
    "checkin": null,  
    "checkout": "2026-01-01"  
  },
  "additionalneeds": "books"
}
```
2. Check status code

### Expected result
400 Bad Request     
### Actual result 
200 OK , Response body: "checkin": "1970-01-01"
