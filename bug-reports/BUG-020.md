## BUG-020: 200 OK is returned on multiple endpoints when `totalprice` property is set to an object 
**Priority:** P1  
**Severity:** Critical    
**Created by:** Buha Andrii    

**Endpoint:** `POST /booking`, `PUT /booking/{id}`   
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
Request with  object value of `totalprice` field returns status code 200 OK instead of 400 Bad Request. The booking is created and totalprice is set to null without any error. 
This issue reproduces across multiple endpoints: `POST /booking`, `PUT /booking/{id}`. Actual and expected results are the same for every endpoint.  

### Steps to reproduce
1. Send a `POST /booking`
```
{
  "firstname": "Brandon",
  "lastname": "Sanderson",
  "totalprice": {
    "key": "value"
    }, 
  "depositpaid": true, 
  "bookingdates": {
    "checkin": "2025-01-01",  
    "checkout": "2026-01-01"  
  },
  "additionalneeds": "books"
}
```
2. Check status code

### Expected result
400 Bad Request     
### Actual result 
200 OK, Response body "totalprice": null
