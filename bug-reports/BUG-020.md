## BUG-019: Sending request with string value  of `totalprice` returns 200 OK instead of 400 Bad Request
**Priority:** P1  
**Severity:** Critical    
**Created by:** Buha Andrii    

**Endpoint:** `POST /booking`   
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
Request with  string value of `totalprice` field returns status code 200 OK instead of 400 Bad Request. The booking is created and totalprice is set to null without any error. Note that numeric string value (e.g. "200") is converted to a number in response body 


### Steps to reproduce
1. Send a `POST /booking`
```
{
  "firstname": "Brandon",
  "lastname": "Sanderson",
  "totalprice": "abc",  
  "depositpaid": true, 
  "bookingdates": {
    "checkin": "2025-01-01",  
    "checkout": "2026-01-01"  
  },
  "additionalneeds": "books"
}
```
2. Check status code

### Expected result
400 Bad Request     
### Actual result 
200 OK, Response body "totalprice": null
