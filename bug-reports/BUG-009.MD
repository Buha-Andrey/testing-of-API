## BUG-009: POST /booking returns 200 OK instead of 201 Created when valid request is sent
**Priority:** P3  
**Severity:** Trivial    
**Created by:** Buha Andrii    

**Endpoint:** `GET /booking/{id}`   
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
POST /booking endpoint returns status code 200 OK instead of status code 201 Created when valid request is sent. All data in the request body is valid and the booking is created.


### Steps to reproduce
1. Send a `POST /booking` with valid data

```
Content-Type = application/json

{
  "firstname": "Brandon",
  "lastname": "Sanderson",
  "totalprice": 100,  
  "depositpaid": true, 
  "bookingdates": {
    "checkin": "2025-01-01",  
    "checkout": "2026-01-01"  
  },
  "additionalneeds": "books"
}
```

2. Check status code

### Expected result
201 Created  

### Actual result 
200 OK
