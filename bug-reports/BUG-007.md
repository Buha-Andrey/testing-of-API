## BUG-007: GET /booking/{id} endpoint returns 404 Not Found when Accept header is missing from the request
**Priority:** P3  
**Severity:** Trivial    
**Created by:** Buha Andrii    

**Endpoint:** `GET /booking/{id}`   
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
GET /booking/{id} endpoint returns status code 404 Not Found instead of status code 400 Bad Request without header Accept in the request


### Steps to reproduce
1. Send a `POST /booking` request to create a test booking.
2. Send a `GET /booking{id}` with id from created booking in step 1. Unset Accept header. 
4. Check status code

### Expected result
400 Bad Request    

### Actual result 
404 Not Found
