## BUG-028: POST /booking returns 200 OK when `checkin` date is later than `checkout` date
**Priority:** P2  
**Severity:** Critical    
**Created by:** Buha Andrii    

**Endpoint:** `POST /booking`   
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
There is possibility that user can create booking with `checkin` date later than `checkout` date. Such case returns 200 OK instead of 422 Unprocessable Entity.

### Steps to reproduce
1. Send a `POST /booking`
```
{
  "firstname": "Brandon",
  "lastname": "Sanderson",
  "totalprice": 1000
  "depositpaid": true, 
  "bookingdates": {
    "checkin": "2027-01-01",  
    "checkout": "2026-01-01"  
  },
  "additionalneeds": "books"
}
```
2. Check status code

### Expected result
422 Unprocessable Entity      
### Actual result 
200 OK , Response body: "checkin": "2027-01-01", "checkout": "2026-01-01"
