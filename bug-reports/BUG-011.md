## BUG-011: POST /booking returns 418 I'm a teapot when header Accept is missing in the request
**Priority:** P3  
**Severity:** Trivial    
**Created by:** Buha Andrii    

**Endpoints:** `POST /booking`, `PUT /booking/{id}`   
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
POST /booking endpoint returns status code 418 I'm a teapot instead of 400 Bad Request when the request without header Accept is sent

### Steps to reproduce
1. Send a `POST /booking` without header Accept
2. Check status code

### Expected result
400 Bad Request  

### Actual result 
418 I'm a teapot  


**Additional info:**  
This issue reproduce also with PUT /booking/{id}. Same case: Endpoint returns 418 I'm a teapot instead of 400 Bad Request when the request without header Accept is sent.
