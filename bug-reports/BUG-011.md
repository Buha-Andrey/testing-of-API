## BUG-010: POST /booking returns 500 Internal Server Error instead of 400 Bad Request when the request without header Content-Type is sent
**Priority:** P2  
**Severity:** Major    
**Created by:** Buha Andrii    

**Endpoint:** `GET /booking/{id}`   
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
POST /booking endpoint returns status code 500 Internal Server Error instead of 400 Bad Request when the request without header Content-Type is sent. 

### Steps to reproduce
1. Send a `POST /booking` without header Content-Type
2. Check status code

### Expected result
400 Bad Request  

### Actual result 
500 Internal Server Error
