## BUG-006: API documentation has an incorrect description of the `checkout` parameter for GET /booking request
**Priority:** P1  
**Severity:** Trivial    
**Created by:** Buha Andrii    

**Endpoint:** `GET /booking`   
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
API documentation has the following description about checkout parameter of the GET /booking request  "Return bookings that have a checkout date greater than or equal to the set checkout date". There is no possibility to filter correctly the bookings with checkout parameter in such case.   

### Steps to reproduce
1. Send a `POST /booking` request to create a test booking with `firstname = "RestfulBooker"`, `lastname = "Test"` and `checkout = 2025-12-31` query parameters.
2. Send a `GET /booking?firstname=RestfulBooker&lastname=Test&checkout=2025-11-1` 
3. Check response body

### Expected result
Response body contains id of created test booking in step 1 according to API documentation 

### Actual result 
Empty array

**Additional info:**    
Server responds is okey. The issue only in description of the checkout parameter in API documentation
