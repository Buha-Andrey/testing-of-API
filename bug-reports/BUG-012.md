## BUG-012: POST /booking returns 500 Internal Server Error when the request is sent with invalid value of Content-Type header
**Priority:** P2  
**Severity:** Major    
**Created by:** Buha Andrii    

**Endpoint:** `GET /booking/{id}`   
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
POST /booking returns 500 Internal Server Error instead of 400 Bad Request when the request is sent with invalid value of Content-Type header. We send request body in json format, so other than json will be invalid. 

### Steps to reproduce
1. Send a `POST /booking`
```
Content-Type = text/plain
```
4. Check status code

### Expected result
400 Bad Request  

### Actual result 
500 Internal Server Error
