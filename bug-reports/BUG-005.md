## BUG-005: Booking is absent from GET /booking response when query parameter `checkin` is equal to the request body parameter `checkin`
**Priority:** P1  
**Severity:** Major    
**Created by:** Buha Andrii    

**Endpoint:** `GET /booking`   
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
According to the documentation GET /booking request have to return booking that has a checkin date equal to the set checkin date

### Steps to reproduce
1. Send a `POST /booking` request to create a test booking with unique firstname and lastname. 
2. Send a `GET /booking` request with same firstname, lastname and chekin parameters 
3. Check response body

### Expected result
Response body contains id of created test booking in step 1

### Actual result 
Empty array
