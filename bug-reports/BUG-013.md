## BUG-013: 200 OK is returned on multiple endpoints when `firstname`/`lastname` properties are set to an empty string
**Priority:** P1  
**Severity:** Critical    
**Created by:** Buha Andrii    

**Endpoint:** `POST /booking`,`PUT /booking/{id}`         
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
Request with an empty string as the `firstname`/`lastname` value returns status code 200 Ok instead of 422 Unprocessable Entity.  Server accepts empty string and doesn't handle the error. 
This issue reproduces across multiple endpoints: `POST /booking`,`PUT /booking/{id}`. Actual and expected results are the same for every endpoint.  

### Steps to reproduce
1. Send a `POST /booking`
```
{
  "firstname": "",
  "lastname": "",
  "totalprice": 100,  
  "depositpaid": true, 
  "bookingdates": {
    "checkin": "2025-01-01",  
    "checkout": "2026-01-01"  
  },
  "additionalneeds": "books"
}
```
2. Check status code

### Expected result
422 Unprocessable Entity   
### Actual result 
200 Ok , Response body: "firstname": "", "lastname": ""
