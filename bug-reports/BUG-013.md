## BUG-012: `firstname` field validation: sending request with empty string `firstname` returns 200 Ok instead of 422 Unprocessable Entity
**Priority:** P1  
**Severity:** Critical    
**Created by:** Buha Andrii    

**Endpoint:** `POST /booking`   
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
Request with an empty string as the `firstname` value returns status code 200 Ok instead of 422 Unprocessable Entity. Server accepts empty string and doesn't handle the error

### Steps to reproduce
1. Send a `POST /booking`
```
{
  "firstname": "",
  "lastname": "Sanderson",
  "totalprice": 100,  
  "depositpaid": true, 
  "bookingdates": {
    "checkin": "2025-01-01",  
    "checkout": "2026-01-01"  
  },
  "additionalneeds": "books"
}
```
2. Check status code

### Expected result
422 Unprocessable Entity   
### Actual result 
200 Ok
