## BUG-014: 500 Internal Server Error is returned on multiple endpoints when `firstname`/`lastname` properties are set to a number
**Priority:** P2  
**Severity:** Major    
**Created by:** Buha Andrii    

**Endpoints:** `POST /booking`, `PUT /booking/{id}   
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
Request with numeric value of the `firstname`/`lastname` returns status code 500 Internal Server Error instead of 400 Bad Request. This issue reproduces across multiple endpoints: `POST /booking`, `PUT /booking/{id}`. Actual and expected results are the same for every endpoint.  

### Steps to reproduce
1. Send a `POST /booking`
```
{
  "firstname": 100,
  "lastname": 100,
  "totalprice": 100,  
  "depositpaid": true, 
  "bookingdates": {
    "checkin": "2025-01-01",  
    "checkout": "2026-01-01"  
  },
  "additionalneeds": "books"
}
```
2. Check status code

### Expected result
400 Bad Request     
### Actual result 
500 Internal Server Error
