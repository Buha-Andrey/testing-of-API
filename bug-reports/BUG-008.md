## BUG-008: GET /booking/{id} returns 404 Not Found instead of 400 Bad Request for non-numeric ID
**Priority:** P3  
**Severity:** Trivial    
**Created by:** Buha Andrii    

**Endpoint:** `GET /booking/{id}`   
**Environment:** URL https://restful-booker.herokuapp.com; Tool Postman v12.22.4

### Description
GET /booking/{id} endpoint returns status code 404 Not Found instead of status code 400 Bad Request when ID is a text value


### Steps to reproduce
1. Send a `GET /booking/abc`
2. Check status code

### Expected result
400 Bad Request   

### Actual result 
404 Not Found
